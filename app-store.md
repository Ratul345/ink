### App Store Screenshots
**Required:** 6.5" display (iPhone 14 Pro/15 Pro) and 6.7" display (iPhone 14 Pro Max/15 Pro Max)
**Recommended:** Also create 5.5" display (iPhone 8 Plus) and iPad Pro screenshots

**Screenshot Guidelines:**
1. Show the main note list with a few sample notes
2. Show the note editor with some content
3. Show the search functionality
4. Show both light and dark theme versions
5. Show an empty state (no notes)
6. Show the app in use (keyboard visible while typing)

**Screenshot Requirements:**
- PNG or JPEG format
- 72 DPI, RGB, flattened, no transparency
- High quality (no compression artifacts)
- No marketing borders or device frames
- Must show actual app content (no mockups)

### App Preview Video (Optional but Recommended)
- 15-30 seconds long
- Show the core functionality: creating a note, searching, theme switching
- No audio required
- Must be device-specific resolution

### App Icon
- 1024x1024 pixels
- PNG format
- No transparency
- No rounded corners (iOS will add them)
- Must match your app icon exactly

## Review Process Notes

### Common Rejection Reasons to Avoid:
1. **App Completeness:** Ensure all features work properly
2. **Metadata Accuracy:** Screenshots and description must match the app
3. **Placeholder Content:** Remove any placeholder text or images
4. **Performance:** App must launch quickly and run smoothly
5. **User Interface:** Follow iOS Human Interface Guidelines

### Testing Checklist:
- [ ] App launches without crashes
- [ ] All buttons and navigation work
- [ ] Notes can be created, edited, and deleted
- [ ] Search functionality works
- [ ] Theme switching works
- [ ] App works offline
- [ ] No placeholder content remains
- [ ] App works on different screen sizes

### Submission Process:
1. Archive and upload build through Xcode
2. Complete App Store Connect metadata
3. Submit for review
4. Typical review time: 24-48 hours
5. Respond promptly to any reviewer questions
